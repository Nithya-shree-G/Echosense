# EchoSense – Emotional Intelligence Companion

EchoSense is an AI-powered emotional intelligence companion designed to understand users' emotions during conversations and provide supportive responses. The project focuses on identifying emotions such as sadness, anger, anxiety, loneliness, gratitude, and joy.

## Project Description

EchoSense provides an interactive platform where users can share their thoughts and feelings through conversations. The system analyzes emotional patterns and provides supportive suggestions based on the user's emotional state.

The project aims to create a safe, simple, and user-friendly experience that helps users understand and express their emotions.
