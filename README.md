# EchoSense – Emotional Intelligence Companion

EchoSense is an AI-powered emotional intelligence companion designed to understand emotions during conversations and provide supportive responses.

## My Contribution

I worked on the UI/UX design of EchoSense using Figma. I designed the overall visual interface and user interaction layouts, including the chat interface, emotion analysis dashboard, emotion indicators, AI insights, and supportive suggestion cards.

My focus was on creating a clean, simple, accessible, and user-friendly interface.

## Tool Used

- Figma

## Project

EchoSense is a team project. The frontend development, AI/ML implementation, and other technical components were developed by my teammates.
